# Gately v0.6.0.2 publié

28 octobre 2026

Il s’agit d’une mise à jour corrective de la série v0.6.0, sans nouvelle fonctionnalité. La mise à niveau est recommandée à tous les utilisateurs.

[Télécharger v0.6.0.2](/fr/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.0.2)

## Terminal web depuis le bureau fnOS

Lorsque l’application fnOS était ouverte depuis son icône du bureau, le [terminal web](/fr/docs/modules/terminal) restait sur « Connexion » puis échouait pour les shells locaux, SSH et Telnet ([#31](https://github.com/wangwanjie/gately/issues/31)), alors que l’accès direct par le port 16680 fonctionnait. L’entrée du bureau passe par le socket Unix de la passerelle unifiée, sur lequel la mise à niveau WebSocket ne pouvait pas reprendre la connexion. L’entrée du bureau se comporte désormais comme l’accès direct, et le journal d’audit n’enregistre 101 qu’une fois la connexion reprise.

## File Browser avec un répertoire de configuration relatif

Lancé avec `./gately` et le répertoire de configuration par défaut `data`, le File Browser géré échouait à chaque démarrage avec `fork/exec data/bin/filebrowser: no such file or directory`. Le répertoire de configuration est désormais converti en chemin absolu au démarrage : File Browser, frp, cloudflared, Tailscale et Docker Compose reçoivent des chemins absolus pour le programme, la configuration et la base de données, et un chemin de programme relatif dans les réglages d’un module continue de fonctionner. Les paquets Docker, fnOS et OpenWrt utilisaient déjà des chemins absolus et ne sont pas concernés.

## Les réponses de l’API ne traduisent plus le contenu des utilisateurs

Dans toute langue autre que le chinois simplifié (y compris pour les scripts sans en-tête `Accept-Language`, qui reçoivent la langue du serveur), les réponses de configuration remplaçaient les fragments chinois de quatre caractères ou plus par des traductions : une remarque d’écouteur comme 由端口转发 SNI 分流… revenait sous la forme 由Port forwarding SNI 分流…, et enregistrer ce qui avait été lu écrivait la traduction dans la configuration. Seuls les champs de message produits par Gately (erreurs, conseils, avertissements, notes d’état, etc.) sont désormais traduits ; les noms, remarques, groupes, commandes, domaines et valeurs d’enregistrement sont renvoyés tels qu’enregistrés, et les tâches cron, les tâches DDNS et l’historique de configuration ne sont plus traduits en entier. Voir « Langue des réponses » dans la [référence de l’API](/fr/docs/reference/api).

## Notes de mise à niveau

- Les remarques déjà réécrites ne sont pas restaurées automatiquement ; retrouvez le texte d’origine dans l’historique de configuration et corrigez-les à la main.
- Docker : récupérez la nouvelle image et recréez le conteneur. OpenWrt : installez le nouveau `.apk` / `.ipk` par-dessus l’ancien. fnOS : installez le nouveau `.fpk` dans le Centre d’applications. Les autres installations peuvent être mises à niveau en ligne dans les Paramètres.
