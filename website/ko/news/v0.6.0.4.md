# Gately v0.6.0.4 출시

2026년 10월 29일

[v0.6.0.4 다운로드](/ko/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.0.4)

## OpenWrt LuCI 앱

릴리스에 아키텍처와 무관한 LuCI 앱 `luci-app-gately_v0.6.0.4_openwrt_all.ipk` / `.apk`가 추가되었습니다. Gately를 설치한 뒤 설치하면 LuCI에 「서비스 → Gately」 페이지가 생깁니다:

- 실행 상태, PID, 버전, 메모리 사용량, 부팅 시 자동 시작, 관리 주소, 설정 디렉터리 확인;
- 서비스 시작·중지·재시작, 부팅 시 자동 시작 켜기·끄기;
- Gately 관리 화면을 한 번에 열기(전역 설정의 보안 입구가 링크에 포함됨). 관리 화면이 루프백에서만 수신하거나 "내부망 접근만 허용"이 켜져 있으면 안내가 표시됩니다;
- 관리 화면 포트 설정. 포트는 `/etc/config/gately`에 저장되며 전역 설정 수신 주소의 포트만 바꿉니다. 루프백이나 내부망 주소에서만 수신하는 설정은 그대로 유지됩니다. 포트 충돌이나 잘못된 포트로 관리 화면이 열리지 않을 때 여기서 되돌릴 수 있고, 비워 두면 전역 설정을 따릅니다.

앱 화면은 LuCI의 언어 설정을 따르며 10개 언어를 지원하고, OpenWrt 24.10(opkg)과 25.12(apk)에서 테스트했습니다. 설치 방법은 [설치 및 배포 · LuCI 앱](/ko/docs/guide/install#openwrt-luci)을 참고하세요.

## 리디렉션 사이트 변수

리디렉션 사이트의 대상 주소에는 `{host}` 외에 다음 변수를 쓸 수 있습니다:

- `{path}` / `{PATH}`, `{args}` / `{Args}`: 원래 요청의 경로와 쿼리 문자열. "경로와 매개변수 유지"가 켜져 있으면 대상에 쓴 부분은 다시 붙이지 않습니다;
- `{port}`, `{hostAndPort}`, `{domainPartN}`, `{pathPartN}`, `{ClientIP}`, `{RemoteIP}`, `{time}`;
- `{1}`: 사이트 도메인 `*.example.com`에서 `*`와 일치한 부분;
- `{STUN_규칙이름_PORT}` / `_IP` / `_ADDR`: [STUN 통과](/ko/docs/modules/stun) 규칙의 현재 공인 주소. 포트가 바뀌어도 사이트를 수정할 필요 없이 다음 요청부터 새 포트로 이동합니다. 규칙이 비활성화되었거나, 아직 통과에 성공하지 않았거나, 자동 재시도 중이면 사이트는 503을 반환하고 실행 로그에 이유를 남깁니다.

예를 들어 CDN을 거치는 `*.example.com`은 `https://{1}.v4.example.com:{STUN_web_PORT}{path}{args}`로 이동하게 할 수 있습니다. 저장할 때 예시 값으로 대상 주소를 검사합니다. 접속 시 변수를 펼친 대상에 호스트가 없으면 503을, 방문자 도메인에 `&`, `=`, `/`처럼 도메인에 쓰이지 않는 문자가 있으면 400을 반환하므로 다른 사이트로 보내지지 않습니다. 가져온 설정에 이런 변수가 들어간 리디렉션이 있으면 주소 검증 실패로 리스너 전체를 건너뛰었지만, 이제 정상적으로 가져옵니다. 자세한 내용은 [웹 서비스 · 리디렉션 변수](/ko/docs/modules/web#redirect-vars)를 참고하세요.

## 공유 사용자와 OIDC 클라이언트 요약 표시

"웹 서비스 → 전역 설정"의 공유 사용자와 OIDC 클라이언트가 항목마다 한 줄 요약으로 바뀌었습니다. 공유 사용자는 사용자 이름, TOTP와 비밀번호 상태, 그룹, 표시 이름, 이메일, 비고를 보여 주고, OIDC 클라이언트는 이름, 기밀 또는 공개 유형, 복사할 수 있는 Client ID, 리디렉션 URI 개수, 허용 사용자, 비고를 보여 줍니다. 새로 만들어 아직 저장하지 않은 시크릿과 리디렉션 URI 누락은 따로 표시됩니다. "편집" 또는 "추가"를 누르면 대화상자에서 모든 항목을 수정할 수 있고, "확인"을 눌러야 반영되며 "취소"하면 변경이 버려집니다. 사용자 이름은 비우거나 중복할 수 없고, Client ID는 반드시 입력해야 하며 중복될 수 없습니다.

## 업그레이드 안내

- Docker는 새 이미지를 받은 뒤 컨테이너를 다시 만드세요. OpenWrt는 새 `.apk` / `.ipk`를 덮어 설치하고, LuCI 페이지가 필요하면 `luci-app-gately`도 설치하세요. fnOS는 앱 센터에서 새 `.fpk`를 설치하세요. 그 밖의 설치 방식은 "시스템 설정"에서 온라인 업그레이드할 수 있습니다.
