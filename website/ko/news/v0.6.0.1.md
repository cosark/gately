# Gately v0.6.0.1 출시

2026년 10월 27일

v0.6.0의 보충 업데이트입니다. v0.6.0에서 Web 서비스 사이트에 추가한 그룹과 정렬을 동적 도메인과 포트 포워딩으로 넓히고, 일괄 작업과 그룹 이름 변경을 더했습니다.

[v0.6.0.1 다운로드](/ko/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.0.1)

## 동적 도메인과 포트 포워딩의 그룹과 정렬

DDNS 작업과 포트 포워딩 규칙에 "그룹"(최대 64자)을 지정할 수 있습니다. 목록은 그룹별로 접을 수 있는 구역으로 표시되고 접힘 상태는 브라우저에 저장됩니다. 페이지 상단에 검색 상자가 추가되어 DDNS는 이름, 그룹, 도메인, 제공업체로, 포트 포워딩은 이름, 그룹, 수신 포트, 대상, SNI 도메인으로 거를 수 있습니다. "정렬"을 눌러 정렬 모드로 들어가면 항목을 위아래로 옮기거나 그룹 전체를 옮기거나 끌어서 정렬할 수 있습니다. 자세한 내용은 [동적 도메인](/ko/docs/modules/ddns)과 [포트 포워딩](/ko/docs/modules/portforward)을 참고하세요.

## 그룹 일괄 설정과 여러 항목 끌기

Web 서비스, 동적 도메인, 포트 포워딩 페이지의 정렬 모드에서 여러 항목을 선택할 수 있습니다.

- 항목마다 체크박스가 있고, 그룹 제목의 체크박스로 그룹 전체를 선택합니다.
- 선택한 항목 중 하나를 끌면 모든 선택 항목이 지금 순서대로 함께 이동합니다. 다른 그룹의 항목이나 그룹 제목에 놓으면 그 그룹으로 들어갑니다.
- 도구 모음에서 그룹 이름을 입력하거나 고른 뒤 "그룹으로 이동"을 누르면 선택 항목을 그 그룹 끝으로 한 번에 옮깁니다. 비워 두면 그룹에서 뺍니다.

## 그룹 이름 변경

그룹 제목에 마우스를 올리고 연필 버튼을 누르면 이름을 바꿀 수 있습니다. 그룹의 항목도 함께 새 이름으로 바뀌며 위치와 순서는 그대로입니다. 이미 있는 그룹 이름을 고르면 확인 후 두 그룹이 합쳐집니다. 사이트는 [Web 서비스](/ko/docs/modules/web)를 참고하세요.

## API

`PUT /api/ddns/tasks-group`과 `PUT /api/portforward/rules-group`이 추가되었습니다. `{"keys": [...], "group": "..."}`로 여러 항목의 그룹을 한 번에 설정하며, `group`이 비어 있으면 그룹에서 뺍니다. 작업과 규칙에 `group` 필드가 추가되었습니다. 순서 변경은 기존 `-order` 엔드포인트를 그대로 사용합니다.

## 업그레이드 안내

- 업그레이드 후 기존 작업과 규칙은 모두 그룹이 없으므로 목록은 이전과 같습니다.
- 그룹과 순서는 관리 화면 표시에만 영향을 줍니다. 바꿔도 DDNS를 다시 확인하거나 포트 포워딩을 다시 시작하지 않으며, 열린 연결도 유지됩니다.
