# Вышел Gately v0.6.0.2

28 октября 2026 г.

Это исправляющее обновление серии v0.6.0 без новых функций. Обновиться рекомендуется всем.

[Скачать v0.6.0.2](/ru/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.0.2)

## Веб-терминал с рабочего стола fnOS

Если приложение fnOS открывали значком на рабочем столе, [веб-терминал](/ru/docs/modules/terminal) для локальной оболочки, SSH и Telnet зависал на «Подключение» и затем завершался ошибкой ([#31](https://github.com/wangwanjie/gately/issues/31)), тогда как прямой доступ через порт 16680 работал. Вход с рабочего стола идёт через Unix-сокет единого шлюза, и при переходе на WebSocket соединение не удавалось перехватить. Теперь вход с рабочего стола работает так же, как прямой доступ, а журнал аудита записывает 101 только после успешного перехвата соединения.

## File Browser с относительным каталогом конфигурации

При запуске `./gately` со стандартным каталогом конфигурации `data` управляемый File Browser при каждом старте падал с ошибкой `fork/exec data/bin/filebrowser: no such file or directory`. Теперь каталог конфигурации при запуске преобразуется в абсолютный путь, и File Browser, frp, cloudflared, Tailscale и Docker Compose получают абсолютные пути к программе, конфигурации и базе данных; относительный путь к программе в настройках модуля по-прежнему работает. Пакеты Docker, fnOS и OpenWrt и раньше использовали абсолютные пути и не затронуты.

## Ответы API больше не переводят пользовательские данные

Для любого языка, кроме упрощённого китайского (в том числе для скриптов без заголовка `Accept-Language`, которые получают язык сервера), ответы с конфигурацией заменяли китайские фрагменты от четырёх символов переводом: примечание слушателя вроде 由端口转发 SNI 分流… возвращалось как 由Port forwarding SNI 分流…, а сохранение прочитанного записывало перевод в конфигурацию. Теперь переводятся только поля сообщений, которые формирует Gately (ошибки, подсказки, предупреждения, пояснения к состоянию и т. п.); имена, примечания, группы, команды, домены и значения записей возвращаются в сохранённом виде, а задачи cron, задачи DDNS и история конфигурации больше не переводятся целиком. Подробнее — раздел «Язык ответов» в [справочнике API](/ru/docs/reference/api).

## Об обновлении

- Уже переписанные примечания автоматически не восстанавливаются; исходный текст можно найти в истории конфигурации и вернуть вручную.
- Docker: скачайте новый образ и пересоздайте контейнер. OpenWrt: установите новый `.apk` / `.ipk` поверх старого. fnOS: установите новый `.fpk` в Центре приложений. Остальные установки можно обновить онлайн в настройках.
