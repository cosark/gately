# Gately v0.6.0.4 リリース

2026年10月29日

[v0.6.0.4 をダウンロード](/ja/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.0.4)

## OpenWrt 向け LuCI アプリ

リリースにアーキテクチャに依存しない LuCI アプリ `luci-app-gately_v0.6.0.4_openwrt_all.ipk` / `.apk` が加わりました。Gately のインストール後に導入すると、LuCI に「サービス → Gately」ページが追加されます：

- 実行状態、PID、バージョン、メモリ使用量、自動起動、管理アドレス、設定ディレクトリを確認する；
- サービスの開始・停止・再起動、自動起動の有効化・無効化；
- Gately の管理画面をワンクリックで開く（グローバル設定のセキュリティ入口もリンクに含まれます）。管理画面がループバックのみで待ち受けている場合や「LAN 内からのみ許可」がオンの場合は注意が表示されます；
- 管理画面のポートを設定する。ポートは `/etc/config/gately` に保存され、全体設定の待ち受けアドレスのポートだけを置き換えます。ループバックや LAN アドレスのみで待ち受ける設定はそのままです。ポートの競合や設定ミスで管理画面が開けないときはここで戻せます。空欄なら全体設定に従います。

アプリの画面は LuCI の言語設定に従い、10 言語に対応しています。OpenWrt 24.10（opkg）と 25.12（apk）でテスト済みです。導入手順は [インストールとデプロイ · LuCI アプリ](/ja/docs/guide/install#openwrt-luci) を参照してください。

## リダイレクトサイトの変数

リダイレクトサイトの転送先では、`{host}` に加えて次の変数が使えるようになりました：

- `{path}` / `{PATH}`、`{args}` / `{Args}`：元のリクエストのパスとクエリ文字列。「パスとパラメーターを保持」がオンのとき、転送先に書いた側は重ねて追加されません；
- `{port}`、`{hostAndPort}`、`{domainPartN}`、`{pathPartN}`、`{ClientIP}`、`{RemoteIP}`、`{time}`；
- `{1}`：サイトドメイン `*.example.com` の `*` に一致した部分；
- `{STUN_ルール名_PORT}` / `_IP` / `_ADDR`：[STUN 穿孔](/ja/docs/modules/stun) ルールの現在のパブリックアドレス。ポートが変わってもサイトを編集する必要はなく、次のリクエストから新しいポートへ転送します。ルールが無効、まだ穿孔に成功していない、または自動再試行中の場合、サイトは 503 を返し、実行ログに理由を記録します。

たとえば CDN 経由の `*.example.com` は `https://{1}.v4.example.com:{STUN_web_PORT}{path}{args}` へ転送できます。保存時にはサンプル値で転送先を検証します。アクセス時は、変数を展開した転送先にホストがない場合は 503 を返し、訪問者のドメインに `&`、`=`、`/` などドメインに現れない文字が含まれる場合は 400 を返すため、別のサイトへ誘導されることはありません。インポートした設定にこうした変数を含むリダイレクトがあると、アドレス検証に失敗してリスナー全体がスキップされていましたが、正常にインポートできるようになりました。詳細は [Web サービス · リダイレクト変数](/ja/docs/modules/web#redirect-vars) を参照してください。

## 共有ユーザーと OIDC クライアントの概要表示

「Web サービス → 全体設定」の共有ユーザーと OIDC クライアントは、1 件につき 1 行の概要表示になりました。共有ユーザーにはユーザー名、TOTP とパスワードの状態、グループ、表示名、メール、備考が表示されます。OIDC クライアントには名前、機密またはパブリックの種別、コピーできる Client ID、リダイレクト URI の数、許可ユーザー、備考が表示され、未保存の新しいシークレットやリダイレクト URI の未入力は個別に表示されます。「編集」または「追加」をクリックするとダイアログですべての項目を変更でき、「OK」を押したときだけ反映され、「キャンセル」で変更を破棄します。ユーザー名は空欄や重複を指定できず、Client ID は必須で重複できません。

## アップグレードの注意

- Docker は新しいイメージを pull してコンテナーを作り直してください。OpenWrt は新しい `.apk` / `.ipk` を上書きインストールし、LuCI ページが必要な場合は `luci-app-gately` も導入してください。fnOS はアプリセンターで新しい `.fpk` をインストールしてください。その他の環境は「システム設定」からオンラインでアップグレードできます。
