# Gately v0.6.0.1 リリース

2026年10月27日

v0.6.0 の追加アップデートです。v0.6.0 で Web サービスのサイトに加えたグループ分けと並べ替えをダイナミック DNS とポート転送にも広げ、一括操作とグループ名の変更を追加しました。

[v0.6.0.1 をダウンロード](/ja/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.0.1)

## ダイナミック DNS とポート転送のグループと並べ替え

DDNS タスクとポート転送ルールに「グループ」（最大 64 文字）を設定できます。一覧はグループごとに折りたためるセクションで表示され、折りたたみ状態はブラウザに保存されます。ページ上部に検索ボックスを追加し、DDNS は名前・グループ・ドメイン・プロバイダ、ポート転送は名前・グループ・待ち受けポート・転送先・SNI ドメインで絞り込めます。「並べ替え」で並べ替えモードに入り、上下移動、グループごとの移動、ドラッグができます。詳しくは [ダイナミック DNS](/ja/docs/modules/ddns) と [ポート転送](/ja/docs/modules/portforward) を参照してください。

## グループの一括設定と複数選択のドラッグ

Web サービス、ダイナミック DNS、ポート転送の並べ替えモードで複数選択ができるようになりました。

- 各項目にチェックボックスがあり、グループ見出しのチェックボックスでグループ全体を選択できます。
- チェックした項目のどれかをドラッグすると、すべてが今の順序のまままとめて移動します。別グループの項目や見出しにドロップするとそのグループに入ります。
- ツールバーでグループ名を入力または選択して「グループへ移動」を押すと、チェックした項目をそのグループの末尾へ一括で移します。空欄にするとグループから外します。

## グループ名の変更

グループ見出しにマウスを合わせて鉛筆ボタンを押すと名前を変更できます。グループ内の項目もまとめて新しい名前になり、位置と順序は変わりません。既存のグループと同じ名前にすると、確認のうえ 2 つのグループが統合されます。サイトについては [Web サービス](/ja/docs/modules/web) を参照してください。

## API

`PUT /api/ddns/tasks-group` と `PUT /api/portforward/rules-group` を追加しました。`{"keys": [...], "group": "..."}` で複数項目のグループを一括設定し、`group` が空ならグループから外します。タスクとルールに `group` フィールドが加わりました。並べ替えは従来の `-order` エンドポイントを使います。

## アップグレード時の注意

- アップグレード後、既存のタスクとルールはすべてグループなしで、一覧の見た目は以前と同じです。
- グループと順序は管理画面の表示にだけ影響します。変更しても DDNS の再チェックやポート転送の再起動は起きず、確立済みの接続も維持されます。
