# Gately v0.6.0.2 publicado

28 de octubre de 2026

Esta es una actualización de correcciones de la serie v0.6.0, sin funciones nuevas. Se recomienda actualizar a todos los usuarios.

[Descargar v0.6.0.2](/es/download) · [GitHub Release](https://github.com/wangwanjie/gately/releases/tag/v0.6.0.2)

## Terminal web desde el escritorio de fnOS

Al abrir la app de fnOS desde su icono del escritorio, el [terminal web](/es/docs/modules/terminal) se quedaba en «Conectando» y luego fallaba con shells locales, SSH y Telnet ([#31](https://github.com/wangwanjie/gately/issues/31)), mientras que el acceso directo por el puerto 16680 funcionaba. La entrada del escritorio pasa por el socket Unix de la pasarela unificada, donde la actualización a WebSocket no podía tomar la conexión. Ahora la entrada del escritorio se comporta igual que el acceso directo, y el registro de auditoría solo anota 101 cuando la conexión se ha tomado.

## File Browser con un directorio de configuración relativo

Al ejecutar `./gately` con el directorio de configuración predeterminado `data`, el File Browser gestionado fallaba en cada arranque con `fork/exec data/bin/filebrowser: no such file or directory`. Ahora el directorio de configuración se convierte en ruta absoluta al arrancar, de modo que File Browser, frp, cloudflared, Tailscale y Docker Compose reciben rutas absolutas de programa, configuración y base de datos, y una ruta de programa relativa en los ajustes de un módulo sigue funcionando. Los paquetes de Docker, fnOS y OpenWrt ya usaban rutas absolutas y no se ven afectados.

## Las respuestas de la API ya no traducen contenido del usuario

En cualquier idioma distinto del chino simplificado (incluidos los scripts sin cabecera `Accept-Language`, que reciben el idioma del servidor), las respuestas de configuración sustituían fragmentos chinos de cuatro o más caracteres por traducciones; una observación de un listener como 由端口转发 SNI 分流… llegaba como 由Port forwarding SNI 分流…, y guardar lo leído escribía la traducción en la configuración. Ahora solo se traducen los campos de mensaje generados por Gately (errores, sugerencias, advertencias, notas de estado, etc.); nombres, observaciones, grupos, comandos, dominios y valores de registros se devuelven tal como se guardaron, y las tareas cron, las tareas DDNS y el historial de configuración ya no se traducen por completo. Consulte «Idioma de las respuestas» en la [referencia de la API](/es/docs/reference/api).

## Notas de actualización

- Las observaciones que ya se reescribieron no se restauran solas; recupere el texto original en el historial de configuración y cámbielas a mano.
- Docker: descargue la nueva imagen y vuelva a crear el contenedor. OpenWrt: instale el nuevo `.apk` / `.ipk` sobre el anterior. fnOS: instale el nuevo `.fpk` en el Centro de aplicaciones. El resto de instalaciones puede actualizarse en línea desde Ajustes.
